📖 How to use:

      
    
        
  • API Key: Enter your OpenRouter API key for LLM access
    • 
        
  • Problem Description: Describe your classification task (required)
    • 
        
  • Advanced Options: Configure model type, language, batch settings, etc.
    • 
        
  • Platform: Choose your operating system for the correct command format
    • 
        
  • Generate: Click to create your personalized Docker command
    • 
        
  • Copy: Use the copy button to copy the command to your clipboard

💡 Example configurations:

        
    
          
  • Basic sentiment analysis: "Classify text as positive, negative, or neutral sentiment"
    • 
          
  • News categorization: "Classify news articles into sports, politics, technology, or entertainment"
    • 
          
  • Spam detection: "Classify emails as spam or not spam"
    • 
          
  • Language detection: "Classify text by language: English, Spanish, French, or German"
    • 
        

        
        
🔧 Advanced options:

        
    
          
  • --model-type - Choose between tensorflow, torch, or sklearn
    • 
          
  • --activation - Use sigmoid for multi-label, softmax for single-label
    • 
          
  • --lang - Set primary language (english, ukrainian, spanish, etc.)
    • 
          
  • --refinement-cycles - Number of prompt improvement iterations
    • 
          
  • --batch-size - Parallel API requests for faster generation
    • 
          
  • --skip-data-gen - Train only using existing data
    • 
          
  • --use-own-dataset - Use your own dataset (enter filename only, e.g., "my_data.csv")
